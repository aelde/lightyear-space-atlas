LIGHTYEAR — ออกไปไกลแค่ไหน

เว็บพิพิธภัณฑ์อวกาศภาษาไทย จัดจุดหมายตามระยะจากโลก ตั้งแต่เมฆออร์ตที่คาดว่ามีอยู่ถึงกาแล็กซีแอนโดรเมดา

ส่วนสำรวจ
- หน้าเปิดภาพโลกและจักรวาลขนาดใหญ่
- ตัวขยายรัศมีจากโลก ครั้งละหนึ่งปีแสง ระหว่าง 0–10 ปีแสง
- เลือก 12 จุดหมาย พร้อมภาพใหญ่ ระยะ และคำอธิบาย
- กรองช่วง 1–10 ปีแสง และจุดหมายไกลออกไป
- เปลี่ยนจุดหมายด้วยปุ่มก่อนหน้า/ถัดไป หรือปุ่มลูกศรบนคีย์บอร์ดเมื่อตัวสำรวจมีโฟกัส
- เปิดรายละเอียดและแหล่งข้อมูล NASA / ESO
- ดาวน์โหลดภาพรวมทั้ง 12 จุดหมาย

การตีความข้อมูล
เป็นชุดจุดหมายเรียงตามความห่าง ไม่ใช่เส้นทางบินตรงผ่านทุกแห่ง วัตถุอยู่คนละทิศ
ระยะเป็นค่าประมาณ ออร์ตยังไม่มีภาพถ่ายโดยตรง และภาพดาว กาแล็กซี เนบิวลา และหลุมดำเป็นภาพจำลอง ไม่ตามมาตราส่วน
ภาพดาวบาร์นาร์ดใช้ภาพจำลองประเภทดาวแคระแดง ไม่ได้อ้างว่าเป็นภาพถ่ายดาวดวงนั้น

ไฟล์ dist คือเว็บพร้อมใช้งาน ไม่มีขั้นตอน build หรือระบบบัญชีเพิ่มเติม
ไฟล์ภาพ JPG ใน dist เป็นสำเนาสำหรับเว็บ ส่วนต้นฉบับ PNG ของภาพจำลองเก็บใน source-assets
เปิดดูในเครื่องด้วย static HTTP server ที่ชี้ไปยัง dist (ไฟล์ JavaScript ใช้ ES modules)
สภาพแวดล้อมการเผยแพร่กำหนดใน .openai/hosting.json และเผยแพร่ผ่าน Sites โดยคงการเข้าถึงแบบส่วนตัวสำหรับเจ้าของ

แหล่งข้อมูลแต่ละจุดเก็บใน dist/landmarks.js และแสดงให้ผู้อ่านเปิดอ่านต้นทางได้ในเว็บ
ข้อมูลอ้างอิงได้รับการตรวจในบทสนทนานี้วันที่ 13 ตุลาคม 2026

ภาพ
สร้างด้วย built-in image_gen ภายใต้แนวทางภาพจำลองวิทยาศาสตร์
Prompt หลัก: ภาพจักรวาลสำหรับพิพิธภัณฑ์ออนไลน์ โทนดำกรมท่า รายละเอียดภาพทางขวาประมาณ 65% และพื้นที่มืดทางซ้ายประมาณ 35% สำหรับตัวอักษร ไม่มีข้อความ โลโก้ ยาน หรือดาวเคราะห์เกินขอบเขต
cosmic-hero: ขอบโลกเรืองแสงฟ้าและฝุ่นจักรวาลสีฟ้าม่วง
andromeda-wide: กาแล็กซีกังหันเอียง แกนกลางทอง แขนฟ้าขาวและแนวฝุ่นมืด
proxima-wide: ดาวแคระแดงผิวละเอียด แสงเรืองและการปะทุขนาดเล็กอย่างพอดี
sirius-wide: ดาวฟ้าขาวขนาดใหญ่และดาวแคระขาวคู่ขนาดเล็กกว่าชัดเจน
luhman-wide: ดาวแคระน้ำตาลสองดวง มีลายเมฆและแสงความร้อนเบาบาง
vega-wide: ดาวฟ้าขาวหนึ่งดวง ไม่มีดาวคู่
pleiades-wide: กระจุกดาวฟ้าขาวกับฝุ่นสะท้อนแสง เป็นภาพจำลอง ไม่อ้างตำแหน่งดาวจริง
orion-wide: ก๊าซเนบิวลาสีชมพู ม่วง ฟ้า ฝุ่นมืด และดาวแรกเกิด
sagittarius-wide: เงาหลุมดำกับก๊าซเรืองแสงส้มและการเลนส์ความโน้มถ่วงแบบภาพแนวคิด
lmc-wide: กาแล็กซีบริวารรูปร่างไม่สม่ำเสมอ มีแกนกลางบางและปมกำเนิดดาว ไม่ใช่กังหันสมมาตร
landmarks-poster: ภาพรวมจากงานก่อนหน้าในบทสนทนา

ฟอนต์ Inter และ Noto Sans Thai ใช้ใบอนุญาต SIL Open Font License สำเนาใบอนุญาตอยู่ใน dist/assets/fonts

การตรวจรุ่นสุดท้าย
ตรวจใน Codex In-app Browser ที่ขนาด 1440×1000, 390×844 และ 320×800
ปุ่มบวก 1→2 ปุ่มลบ 2→1 ช่วงปลาย 0 และ 10 รวมถึงปุ่มปิดการใช้งานที่ขอบเขต ผ่าน
เลือกรูปและจุดหมายทั้ง 12 แห่งผ่าน ภาพ JPG ทุกแห่งที่ใช้โหลดสำเร็จ
ตัวกรองเหลือ 6 จุดตามช่วง เปิดรายละเอียด เนื้อหา ระยะ และการไปจุดถัดไปผ่าน
Escape ปิดรายละเอียด เมนูมือถือเปิดและปิดผ่าน
ไม่มีการล้นแนวนอนที่ขนาดจอที่ตรวจ ปุ่มบวก/ลบมีขนาด 44px และแถบเลื่อนมีพื้นที่สูง 32px
ไม่พบข้อผิดพลาดจากคอนโซลระหว่างการตรวจรุ่นสุดท้าย
ภาพหลักและแอนโดรเมดาใช้ภาพจำลองขนาดใหญ่ รายละเอียดและข้อความได้รับการเทียบกับชุดข้อมูลเดิมในบทสนทนา
